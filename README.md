# diploma-salary-prediction
Задача прогнозирования временного зарплатного ряда различными математическими и нейросетевыми методами
## Задача - провести прогнозирование временного ряда различными методами, после чего сравнить эффективность каждого метода для прогнозирования конкретного временного ряда.
## Данные - Взяты данные по средней номинальной заработной плате в Рязани в период с января 2022 года по январь 2026 года включительно
## Инструменты - Pyhton, pandas, matplotlib, numpy, statsmodels,sklearn, scipy, pmdarima, neuralforecast, Jupiter Notebook
## Что сделано - проведён первичный анализ временного ряда, разделение выборки на тестовую и обучающую; 
  реализованы: прогноз с помощью фиктивных пременных, нейронная сеть с одним скрытым слоем, 
  использованы библиотечные реализации: SARIMA, NBEATS,
  Проведён рассчёт метрик качества прогноза для каждой модели,
  Проведено итоговое сравнение всех моделей,
  Визуализация результатов.
## Результаты
  - Итоговая точность каждой модели:
    Фиктивные переменные - RMSE:2701.7 руб.,  MAE:2583.59руб.,  MAPE: 3.4%
    SARIMA - RMSE:1247.7 руб.,  MAE:1203.30 руб., MAPE: 1.55% - 
    Нейронная сеть с 1-м скрытым слоем - RMSE:2706.0 руб.,  MAE: 2290.53руб., MAPE: 3.01%
    N-BEATS - RMSE:2304.6 руб.,  MAE:1620.85руб.,  MAPE: 1.93%
 - Наиболее эффективная модель для данного ряда - SARIMA
